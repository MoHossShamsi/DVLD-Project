# DVLD – Driver’s License Management System

A desktop application built using C# WinForms that manages driver's license-related operations such as applications, exams, renewals, and more. The system is developed with a 3-tier architecture to ensure clean separation of concerns and easy maintainability.

## 🔧 Technologies Used

- **C# WinForms** – For building the desktop user interface
- **.NET Framework** – For application logic
- **MS SQL Server** – For database management
- **ADO.NET** – For database connectivity
- **3-Tier Architecture** – Presentation Layer, Business Logic Layer (BLL), Data Access Layer (DAL)
- **Visual Studio** as the development environment

## 🏗️ Architecture

This project follows the **3-tier architecture**:

1. **Presentation Layer (UI):** Built with WinForms for an intuitive and user-friendly interface.
2. **Business Logic Layer (BLL):** Handles core logic and validation rules.
3. **Data Access Layer (DAL):** Interacts with SQL Server to store and retrieve data securely.


## 🧠 Features

- Create and manage driver’s license applications
- Schedule and evaluate driving tests
- License renewal and expiration tracking
- Role-based access control (Admin / Employee)
- Search and reporting functionality
- Input validation and exception handling
- Modular code structure for easy scaling
